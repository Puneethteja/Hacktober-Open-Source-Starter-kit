Make your first contribution

This site is open source too. Every page here can be improved by you.

  1. Pick an issueFind one labeled good first issue and comment to ask for it.
  2. Make your changeFork the repo, clone your fork, create a branch, and edit the file the issue mentions.
  3. Check itRun node scripts/validate.js and open the site locally to see your change.
  4. Open a pull requestPush your branch and open a PR that says Closes # with the issue number.
